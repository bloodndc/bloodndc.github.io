Moderator sign in

Use the moderator email & password that was created in the Firebase console (Authentication → Users → Add user).

First time? Create the moderator account (one-time, ~2 minutes)
1. In the Firebase console, open Authentication → Sign-in method and enable Email/Password.
2. Open Authentication → Users → Add user, enter the moderator email and a strong password, and save.
3. Publish firestore.rules under Firestore → Rules — it grants moderator powers only to Email/Password accounts.
4. Sign in on this page. The session stays signed in on this device.
